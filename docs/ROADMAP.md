# Roadmap

## Phase 1 — Vertical slice

- CSV/XLSX parsing
- USD-payable validation
- Deterministic INR exposure and risk score
- FastAPI analysis endpoint
- React upload/demo and result UI

## Phase 2 — Scenario simulator

- Scenario USD/INR rate control
- Unhedged scenario cost and additional cost
- Live impact chart and clear assumptions

## Phase 3 — Illustrative mitigation

- Hedge-ratio control
- Explicit assumed hedge rate
- Hedged versus unhedged comparison
- Clear “illustrative, not executable pricing” disclosure

## Phase 4 — AI assistance

- Local-LLM or deterministic text extraction fallback
- Structured-output validation
- Plain-language explanation of already-calculated results

## Phase 5 — Product polish

- Loading, error, responsive, and accessibility refinement
- Optional SQLite persistence and dashboard summaries
- Broader file/batch support

Future exploration: receivables, multiple currencies, live market-data integration with provenance, collaboration, authentication, and additional business-risk modules.
